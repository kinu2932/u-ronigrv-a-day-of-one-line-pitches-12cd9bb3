One sentence, 232 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on
[make.fun](https://make.fun/c/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## Entry

> Tell an AI agent your app idea in plain words and it builds the first
> working version for you on make.fun — no coding, no learning curve, and
> if you don't like it, just describe it differently until you can tap the
> app you imagined.

## How it runs

`main.py` (Python 3.13, standard library only) writes the sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), one line,
no trailing newline, byte-identical on every run.

```sh
python3 main.py
```
